# Bundled typefaces

Arcelira bundles unmodified Inter (normal 400, 500, 600 and 700) and DM Serif
Display (normal 400) WOFF2 files from the Google Fonts CSS API, downloaded on
October 11, 2026. The CSS retains the original Unicode subsets, including
Latin extended/Turkish, Cyrillic, Greek and Vietnamese where supported.

The font binaries and CSS are loaded locally; they do not call Google Fonts
at runtime. System font fallbacks for other writing systems are unchanged.

See OFL-Inter.txt and OFL-DMSerifDisplay.txt for the accompanying copyright
notices and SIL Open Font License 1.1. These notices travel with the font
files in the web and native packages.

Sources: https://github.com/google/fonts/tree/main/ofl/inter and
https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
